# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/JS (ES6 Modules, Vanilla JavaScript)

## Users

Students, cybersecurity enthusiasts, and anyone interested in understanding password security through mathematical probability.

## Product Purpose

Interactive educational presentation demonstrating probability mathematics applied to password cracking via brute force. Makes abstract combinatorial concepts tangible through real-time calculators and live simulations.

## Positioning

A hands-on, visual learning experience that transforms probability theory from equations into interactive demonstrations, showing why password length matters more than complexity through live brute-force simulation.

## Operating Context

Single-page web application used for self-paced learning. No server required. All computation runs client-side in the browser.

## Capabilities and Constraints

- Real-time probability calculation (R^L, 1/R^L, accumulated probability)
- Interactive controls: sliders, checkboxes, inputs
- Live brute-force simulation with async non-blocking execution
- Animated transitions between presentation sections
- Dark cyberpunk aesthetic with neon accents
- Footer attribution: "Desarrollado por Juan Esteban Isaza"

## Brand Commitments

- Dark-mode, Neo-retro, Cyberpunk visual identity
- Terminal/monospace typography for technical data
- Neon color palette (green, cyan, magenta)
- Card-based layout with glowing borders

## Evidence on Hand

None (greenfield project).

## Product Principles

1. Show, don't tell — every concept is demonstrated interactively
2. Mathematical accuracy with visual clarity
3. Non-blocking UI during simulations
4. Modular, maintainable ES6 codebase

## Accessibility & Inclusion

Keyboard navigation for all interactive controls. Sufficient contrast for neon text on dark backgrounds.
